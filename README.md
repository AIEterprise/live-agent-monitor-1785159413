# Live Agent Monitor

Real-time telemetry and execution monitoring web application for Google Antigravity CLI agent runs.

## Features
- Next.js App Router (TypeScript)
- Tailwind CSS (v3.4 locked)
- Charcoal Black base (`#0A0A0A` / `#121212`), Off-White (`#F5F5F7`), Sea Green (`#0EA5E9`), Mint Green (`#10B981`) design system
- Lenis smooth scrolling integration
- GSAP animation ready
- Firebase Realtime Database / Cloud Firestore stream integration

## Getting Started

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
